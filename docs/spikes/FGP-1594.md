# FGP-1594 frontend integration spike

This disposable branch pairs with backend `fgp-1594-spike`. It adds configured
case-list links, a page-type template registry, dedupe summary/group templates,
backend HTTP reads/saves, validation rendering and generic label timeline copy
to the existing frontend application. It uses the existing session, Wreck,
Nunjucks, dynamic components and GOV.UK controls.

See `docs/spikes/FGP-1594.md` in the backend branch for the full design, seeded
run instructions, verification and follow-up ticket drafts. From that backend
checkout, this command drives these actual frontend routes through the backend
and checks MongoDB persistence:

```sh
FGP1594_FRONTEND=/path/to/this/checkout node scripts/verify-dedupe-spike.js
```

The check substitutes the authenticated user; actual Entra login and browser
accessibility checks remain follow-up work. For manual use, run this frontend
normally against the seeded backend and sign in as Test ReaderWriter:

```sh
FG_CW_BACKEND=http://localhost:3101 npm run dev
```

Open `/cases` and choose Clean the list. All dedupe rules, choices, grouping and
status calculation stay in the backend. These branches are throwaway code, not
a production-ready feature.
